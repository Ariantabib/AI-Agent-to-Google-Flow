# ایجنت هوش مصنوعی ← گوگل فلو

**به ایجنت هوش مصنوعی‌ات اجازه بده توی [Google Flow](https://flow.google.com) عکس بسازه؛ ده‌ها عکس، با سرعت معقول، قابل ادامه، و یه گالری در آخر.**

[English](README.md)

به ایجنتت می‌گی «۵۰ تا ایده و استایل مختلف برای پروژه‌ام بساز». یه بار چند تا سؤال تنظیمات می‌پرسه، پرامپت‌ها رو می‌نویسه و گوگل فلو رو توی کروم خودت (که لاگین کردی) کنترل می‌کنه. هر دستهٔ ۱۰تایی رو ارسال می‌کنه، صبر می‌کنه تا ساخته بشن، همه رو دانلود می‌کنه و بعد می‌ره سراغ ۱۰ تای بعدی. آخرش همهٔ عکس‌ها با اسم درست توی یه فولدرن، به‌اضافهٔ یه صفحهٔ گالری.

به دو شکل عرضه می‌شه: **پلاگین Claude Code** (اسکیل + ابزار خط فرمان)، و **ابزار خط فرمان Node** که با هر ایجنتی یا حتی دستی کار می‌کنه.

## چی کار می‌کنه

- **اول می‌پرسه، فقط یه بار:** موضوع پروژه، محل ذخیره، نسبت تصویر، مدل، و کدوم پروژهٔ فلو. همه توی `flow-images.config.json` ذخیره می‌شن.
- **دسته‌های ۱۰تایی:** ۱۰ پرامپت می‌فرسته، صبر می‌کنه تا همه ساخته بشن، همه رو دانلود می‌کنه، بعد ۱۰ تای بعدی. فلو هر دسته رو موازی می‌سازه (حدود ۲ تا ۳ دقیقه برای هر ۱۰ تا).
- **پیست می‌کنه، تایپ نمی‌کنه:** هر پرامپت یکجا وارد می‌شه.
- **می‌دونه هر عکس مال کدوم پرامپته:** پرامپت واقعی هر عکس رو از دکمهٔ *Reuse prompt* خود فلو می‌خونه، با لیست مقایسه می‌کنه و با اسم درست ذخیره می‌کنه (مثلاً `07-pixel-16bit.jpg`).
- **خطاها رو مدیریت می‌کنه:** اگه فلو خطا بده یا پیام *«We noticed some unusual activity»* بیاد، صفحه رو رفرش می‌کنه، کمی صبر می‌کنه و اون پرامپت‌ها رو توی دستهٔ بعدی دوباره می‌فرسته (تا ۳ بار). اگه دو دستهٔ پشت سر هم بیشترشون خطا بدن، متوقف می‌شه و بهت خبر می‌ده.
- **قابل ادامه:** اگه کار وسطش قطع شد، همون دستور رو دوباره اجرا کن. چیزی دوباره ساخته نمی‌شه.
- **به چیزهای تو دست نمی‌زنه:** از یه پروفایل جدای کروم استفاده می‌کنه و به عکس‌هایی که از قبل توی پروژهٔ فلو بودن کاری نداره.
- **گالری:** یه `index.html` توی هر فولدر خروجی. اگه ماوس رو روی هر عکس ببری، پرامپتش رو نشون می‌ده.
- **فقط عکس:** ساخت عکس توی پلن‌های فلو رایگانه. این ابزار هیچ‌وقت ویدیو نمی‌سازه، چون ویدیو کردیت مصرف می‌کنه.

## پیش‌نیازها

- اکانت گوگل با دسترسی به Google Flow
- Google Chrome (همون کروم معمولی)
- Node.js نسخهٔ ۲۰ یا بالاتر
- Claude Code (اختیاری، برای استفاده به‌شکل پلاگین)

## نصب در Claude Code

این دو دستور رو داخل Claude Code بزن:

</div>

```
/plugin marketplace add Ariantabib/AI-Agent-to-Google-Flow
/plugin install google-flow@ai-agent-to-google-flow
```

<div dir="rtl">

بعد توی هر پروژه‌ای فقط بنویس:

> با گوگل فلو ۲۰ تا عکس با استایل‌های مختلف برای این پروژه بساز.

یا مستقیم اسکیل رو صدا بزن: `/google-flow:images`

## اولین اجرا

۱. **بررسی سیستم:** ایجنت `doctor` رو اجرا می‌کنه. اگه لازم باشه، پیش‌نیاز رو نصب می‌کنه و یه **پنجرهٔ کروم جدا** روی گوگل فلو باز می‌کنه.

۲. **لاگین:** توی اون پنجره خودت با اکانت گوگلت لاگین می‌کنی. ایجنت هیچ‌وقت پسوردت رو نمی‌بینه. لاگین توی همون پروفایل جدا می‌مونه و دفعهٔ بعد لازم نیست. کروم اصلیت اصلاً استفاده نمی‌شه.

۳. **سؤال‌های تنظیمات:** موضوع پروژه چیه؟ (اگه پروژه README یا داک طراحی داشته باشه، خودش می‌خونه و یه خلاصه پیشنهاد می‌ده.) عکس‌ها کجا ذخیره بشن؟ کدوم پروژهٔ فلو: آخرین، جدید، یا یه لینک مشخص؟ چه نسبت تصویری؟ چه مدلی؟

۴. **درخواست:** چند تا عکس و دربارهٔ چی. ایجنت پرامپت‌ها رو می‌نویسه، لیستشون رو نشونت می‌ده و اجرا می‌کنه.

۵. **نتیجه:** یه فولدر با همهٔ عکس‌ها، فایل `manifest.json` و صفحهٔ گالری `index.html`.

## استفاده بدون Claude Code

</div>

```bash
npx github:Ariantabib/AI-Agent-to-Google-Flow help
npx github:Ariantabib/AI-Agent-to-Google-Flow login
npx github:Ariantabib/AI-Agent-to-Google-Flow init --topic "موضوع پروژه" --out ./flow-images --aspect 9:16
npx github:Ariantabib/AI-Agent-to-Google-Flow run ./flow-images/my-run
```

<div dir="rtl">

داخل فولدر `my-run` یه فایل `prompts.json` بذار (نمونه‌ها توی [examples](examples)). راهنمای کامل دستورها در [docs/CLI.md](docs/CLI.md) هست.

ایجنت‌های دیگه مثل Codex، Cursor یا Gemini CLI هم می‌تونن از فایل [SKILL.md](plugins/google-flow/skills/images/SKILL.md) به‌عنوان دستورالعمل استفاده کنن.

## امنیت اکانت و حریم خصوصی

لطفاً قبل از استفاده این بخش رو بخون.

- **این یه اتوماسیون غیررسمیه.** هیچ ارتباطی با گوگل نداره و گوگل تأییدش نکرده. ممکنه گوگل استفادهٔ خودکار رو خلاف قوانینش بدونه، و فلو ارسال‌های پشت‌سرهم رو تشخیص می‌ده. این ابزار سرعت رو در حد یه آدم معمولی نگه می‌داره، ولی **هیچ تلاشی برای پنهان کردن اتوماسیون یا دور زدن بررسی‌های گوگل نمی‌کنه**. مسئولیت استفاده با خودته و بهتره از یه اکانت گوگل دوم استفاده کنی.
- **لاگین با خودته** و ابزار هیچ‌وقت پسورد نمی‌بینه.
- **همه‌چیز روی سیستم خودته.** سرور یا ارسال اطلاعات به جای دیگه نداره، فقط کروم با گوگل فلو ارتباط برقرار می‌کنه. وقتی کارت تموم شد پنجرهٔ کروم فلو رو ببند.
- قوانین [استفادهٔ ممنوع از هوش مصنوعی مولد گوگل](https://policies.google.com/terms/generative-ai/use-policy) رو رعایت کن: بدون چهرهٔ آدم‌های واقعی بدون رضایتشون، بدون شخصیت‌های دارای کپی‌رایت.

## رفع مشکل

| مشکل | راه‌حل |
| --- | --- |
| `playwright-core is not installed` | دستور `setup` رو اجرا کن |
| `Not signed in` | دستور `login` رو بزن و توی پنجره‌ای که باز می‌شه لاگین کن |
| خطای زیاد با پیام «unusual activity» | یکی دو ساعت صبر کن، بعد همون دستور `run` رو بزن تا از همون‌جا ادامه بده |
| خطاهای مربوط به تنظیمات یا دانلود | ظاهر فلو عوض شده؛ [راهنمای رفعش](plugins/google-flow/skills/images/reference/fixing-ui-changes.md) |

جزئیات بیشتر در [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) هست.
